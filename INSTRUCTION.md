# OilGasCity — Инструкция по управлению сайтом

> Версия 1.1 — Февраль 2026
> Грант РНФ № 25-27-00022 | ИКЗ ТюмНЦ СО РАН

---

## Что это за инструкция

Эта инструкция поможет вам самостоятельно обновлять и дополнять сайт проекта OilGasCity — добавлять новости, экспедиции, публикации, фотографии, редактировать информацию о городах и участниках проекта. **Никаких навыков программирования не требуется.** Всё делается через визуальный интерфейс в браузере, похожий на работу с обычным текстовым редактором.

---

## Как устроен сайт (простым языком)

Сайт состоит из двух частей:

**Публичный сайт** — то, что видят все посетители в интернете. Здесь отображается информация о проекте, городах, экспедициях, публикациях и команде.

**Панель управления (CMS)** — закрытая часть, доступная только вам по логину и паролю. Здесь вы редактируете весь контент. Изменения в панели управления автоматически появляются на публичном сайте после нажатия кнопки «Опубликовать».

> 💡 **CMS** (Content Management System) — система управления контентом. Это как «задняя комната» магазина, где вы расставляете товары на полках, а покупатели видят уже готовую витрину.

## 2. Вход в панель управления

1. Откройте любой браузер (Chrome, Firefox, Edge)
2. В адресной строке введите: `https://oilgascity.ru/cms/`
3. Откроется страница входа с логотипом Wagtail (птица-трясогузка)
4. В поле **Username** введите ваш логин
5. В поле **Password** введите ваш пароль
6. Нажмите кнопку **Sign in**

**Что вы увидите после входа:**

Откроется главная панель управления. Слева — тёмное боковое меню с разделами. В центре — приветствие и краткая статистика. Это ваше «рабочее место» для управления сайтом.

## 3. Знакомство с интерфейсом

### Боковое меню (слева)

После входа вы увидите тёмную панель слева с несколькими пунктами:

| Пункт меню | Для чего | Как часто будете использовать |
|------------|----------|:---:|
| **Pages** (Страницы) | Управление всем контентом сайта | Постоянно |
| **Images** (Изображения) | Просмотр всех загруженных фото | Иногда |
| **Documents** (Документы) | Загруженные файлы (PDF и др.) | Редко |
| **Settings** (Настройки) | Пользователи и общие настройки | Почти никогда |

> 💡 **90% вашей работы** будет происходить в разделе **Pages**. Именно там находится весь контент сайта.

### Основные кнопки, которые вы будете встречать

| Кнопка / Иконка | Что делает |
|-----------------|-----------|
| 📝 (карандаш) или **Edit** | Открывает страницу для редактирования |
| 👁 (глаз) или **View live** | Показывает, как страница выглядит на сайте |
| ➕ **Add child page** | Создаёт новую страницу внутри текущего раздела |
| ⋮ (три точки) | Показывает дополнительные действия (удалить, копировать и т.д.) |
| **Publish** (зелёная кнопка) | Публикует изменения на сайте |
| **Save Draft** | Сохраняет черновик (на сайте не появится) |

## 4. Структура контента

Контент сайта организован как папки на компьютере — есть «папки-разделы» и «файлы-страницы» внутри них:

```
Root (корень — верхний уровень)
│
├── О проекте .............. Главная страница сайта
│
├── Города ................. Раздел «Города»
│   ├── Муравленко ......... Страница города
│   └── Когалым ............ Страница города
│
├── Экспедиции ............. Раздел «Экспедиции»
│   └── Полевые исследования в г. Муравленко
│
├── Публикации ............. Список статей (все на одной странице)
│
├── Авторский коллектив .... Список участников (все на одной странице)
│
└── Блог ................... Раздел «Новости»
    └── Итоги первого года работы
```

### Два способа добавления контента

**Способ 1 — Дочерняя страница.** Используется для городов, экспедиций и новостей. Каждый город, каждая экспедиция, каждая новость — это отдельная страница. Вы создаёте их кнопкой **Add child page**.

**Способ 2 — Блок на странице.** Используется для публикаций и участников команды. Все записи находятся на одной странице, и вы добавляете их кнопкой **Add** прямо при редактировании.

> 💡 Не переживайте, если пока непонятно — ниже для каждого раздела есть пошаговая инструкция.

## 5. Редактирование главной страницы

Главная страница — это первое, что видят посетители. Здесь размещена информация о проекте, гранте и ожидаемых результатах.

### Как перейти к редактированию

1. В боковом меню нажмите **Pages**
2. Вы увидите одну строку — **Root**. Нажмите на неё
3. Откроется список всех разделов сайта
4. Найдите строку **«О проекте»** (или Home Page)
5. Нажмите на **иконку карандаша** (📝) справа от названия

<!-- Место для скриншота: путь к главной странице -->

### Что можно изменить

| Поле | Что здесь | Пример |
|------|----------|--------|
| **Title** | Короткое название страницы | «О проекте» |
| **Subtitle** | Полное название проекта | «Социально-экологические аспекты...» |
| **Header image** | Изображение в шапке сайта | Фото города сверху |
| **Body** | Основной текст страницы | Описание проекта, цели, задачи |
| **Grant info** | Информация о гранте | «РНФ № 25-27-00022» |
| **Expected results** | Ожидаемые результаты | Текст про результаты |

### Как сохранить

1. Внесите изменения в нужные поля
2. Прокрутите вниз страницы
3. Нажмите зелёную кнопку **Publish** (Опубликовать)
4. Изменения сразу появятся на сайте

> 💡 Если хотите сохранить работу, но пока не показывать на сайте — нажмите **Save Draft** вместо Publish.

## 6. Добавление нового города

### Пошаговый сценарий: добавляем город Ноябрьск

**Шаг 1.** В боковом меню нажмите **Pages**

**Шаг 2.** Нажмите на **Root**

**Шаг 3.** Найдите строку **«Города»** и нажмите на **название** (не на карандаш, а именно на текст «Города»)

> ⚠️ **Частая ошибка:** если нажмёте на карандаш (📝) — откроется редактирование самого раздела «Города». А вам нужно нажать на **текст** «Города», чтобы увидеть список городов внутри и кнопку добавления.

**Шаг 4.** Вы увидите список уже добавленных городов (Муравленко, Когалым). Над ними будет кнопка **Add child page** — нажмите на неё

**Шаг 5.** Появится выбор типа страницы. Выберите **City Page**

**Шаг 6.** Откроется форма нового города. Заполните поля:

| Поле | Что писать | Обязательно? |
|------|-----------|:---:|
| **Title** | Название города: `Ноябрьск` | ✅ Да |
| **Region** | Регион: `ЯНАО` | Нет |
| **Founded** | Год основания: `1975` | Нет |
| **Population** | Население: `106 000` | Нет |
| **Description** | Описание города — любой текст с форматированием | Нет |
| **Header image** | Главное фото города | Нет |

<!-- Место для скриншота: форма создания города -->

**Шаг 7. Добавьте главное фото:**

1. Нажмите **Choose an image** рядом с полем Header image
2. Откроется окно медиабиблиотеки
3. Нажмите вкладку **Upload** вверху
4. Нажмите **Or choose from your computer** и выберите файл с вашего компьютера
5. В поле **Title** введите название (напр. «Панорама Ноябрьска»). Это название для вашего удобства — посетители сайта его не увидят
6. Нажмите синюю кнопку **Upload**
7. Фото появится в поле

<!-- Место для скриншота: окно загрузки изображения -->

**Шаг 8. Добавьте фотогалерею** (необязательно, но рекомендуется):

1. Прокрутите страницу вниз до раздела **Gallery**
2. Нажмите кнопку **Add**
3. Появится блок с двумя полями: **Image** и **Caption**
4. Нажмите **Choose an image** → вкладка **Upload** → загрузите фото
5. В поле **Caption** введите подпись (напр. «Вид на центральную площадь»). Эту подпись увидят посетители под фото
6. Чтобы добавить ещё одно фото — снова нажмите **Add**
7. Повторите для каждого фото (можно добавить сколько угодно)

> 💡 На сайте фото галереи отображаются сеткой. При клике на любое фото оно открывается на весь экран с возможностью листать стрелками.

**Шаг 9.** Прокрутите в самый низ и нажмите зелёную кнопку **Publish**

**Готово!** Откройте сайт → раздел «Города» — новый город уже там.

## 7. Добавление экспедиции

Процесс аналогичен добавлению города.

**Шаг 1.** Pages → Root → нажмите на **текст** «Экспедиции» (не на карандаш!)

**Шаг 2.** Нажмите **Add child page** → выберите **Expedition Page**

**Шаг 3.** Заполните поля:

| Поле | Что писать | Пример |
|------|-----------|--------|
| **Title** | Название экспедиции | «Полевые исследования в г. Когалым» |
| **Date start** | Дата начала | Выберите в календаре или введите: 2025-07-15 |
| **Date end** | Дата окончания | Выберите в календаре или введите: 2025-07-25 |
| **Location** | Место проведения | «г. Когалым, ХМАО» |
| **Description** | Подробное описание | Текст о целях, задачах, результатах |
| **Header image** | Главное фото | Фото из экспедиции |
| **Gallery** | Фотогалерея | Несколько фото с подписями |

**Шаг 4.** Добавьте фотогалерею — точно так же, как для городов (см. Шаг 8 в разделе 6)

**Шаг 5.** Нажмите **Publish**

> 💡 Для поля даты: при клике на поле появляется мини-календарь. Можно также ввести дату вручную в формате ГГГГ-ММ-ДД (например, 2025-07-15 для 15 июля 2025 года).

## 8. Добавление публикации

> ⚠️ **Важное отличие от городов и экспедиций!** Публикации добавляются НЕ как отдельные страницы, а как блоки на одной странице «Публикации». **Не нажимайте** Add child page. Нужно **редактировать** саму страницу «Публикации».

**Шаг 1.** Pages → Root → найдите строку **«Публикации»**

**Шаг 2.** Нажмите на **иконку карандаша** (📝) справа от названия

**Шаг 3.** Откроется страница редактирования. Прокрутите вниз — вы увидите раздел **Publications** со списком уже добавленных статей

**Шаг 4.** Нажмите кнопку **Add** внизу раздела Publications

**Шаг 5.** Появится новый пустой блок. Заполните поля:

| Поле | Что писать | Пример |
|------|-----------|--------|
| **Title** | Название статьи полностью | «Малые города нефтегазового освоения...» |
| **Authors** | Авторы через запятую | «Федоров Р.Ю., Сизов О.С.» |
| **Journal** | Название журнала | «Вестник ТюмГУ» |
| **Year** | Год публикации | 2025 |
| **Abstract** | Аннотация статьи | Краткое описание содержания |
| **DOI** | Полная ссылка на статью | `https://doi.org/10.xxxx/xxxxx` |

> ⚠️ В поле DOI вводите **полный URL**, начиная с `https://`. Просто номер DOI (вида 10.xxxx/xxxxx) не будет работать как ссылка на сайте.

**Шаг 6.** Чтобы добавить ещё одну статью — снова нажмите **Add** и заполните следующий блок

**Шаг 7.** Когда все публикации добавлены — нажмите **Publish**

> 💡 Можно добавить сразу несколько публикаций и нажать Publish один раз в конце.

## 9. Редактирование команды

> ⚠️ Участники команды, как и публикации, добавляются блоками на одной странице. Принцип тот же.

**Шаг 1.** Pages → Root → **Авторский коллектив** → нажмите 📝 (карандаш, Edit)

**Шаг 2.** Прокрутите вниз до раздела **Members**

### Добавление нового участника

**Шаг 3.** Нажмите **Add** внизу раздела Members

**Шаг 4.** Заполните поля:

| Поле | Что писать | Пример | Обязательно? |
|------|-----------|--------|:---:|
| **Name** | ФИО полностью | «Иванов Пётр Сергеевич» | ✅ Да |
| **Role** | Роль в проекте | «Исполнитель» | ✅ Да |
| **Position** | Должность и степень | «к.г.н., ст. науч. сотрудник» | Нет |
| **Organization** | Организация | «ИКЗ ТюмНЦ СО РАН» | Нет |
| **Photo** | Фотография | Нажмите Choose an image → Upload | Нет |
| **ORCID** | Ссылка на ORCID | `https://orcid.org/0000-0002-...` | Нет |
| **Scopus** | Ссылка на Scopus | Полный URL профиля | Нет |
| **WoS** | Ссылка на Web of Science | Полный URL профиля | Нет |
| **eLibrary** | Ссылка на eLibrary | Полный URL профиля | Нет |
| **SPIN code** | SPIN-код РИНЦ | «1234-5678» | Нет |

> 💡 Заполняйте только те поля, информация для которых у вас есть. Пустые поля просто не будут показаны на сайте.

### Изменение порядка участников

Слева от каждого блока участника есть иконка **≡** (три горизонтальные полоски). Зажмите её мышкой и перетащите блок вверх или вниз — порядок на сайте изменится соответственно.

### Удаление участника

Справа от блока участника есть кнопка **Delete** (иконка корзины 🗑). После нажатия блок станет перечёркнутым — это предварительная пометка. Окончательное удаление произойдёт только после нажатия **Publish**.

> 💡 Передумали удалять? Пока не нажали Publish — просто обновите страницу (клавиша F5). Всё вернётся как было.

**Шаг 5.** Нажмите **Publish**

> 💡 Header image — это фото, которое отображается в карточке новости на странице списка новостей, а также вверху самой новости. Рекомендуется всегда добавлять его — с фото новость выглядит привлекательнее.

## 11. Работа с изображениями

### Загрузка фото при редактировании страницы

1. Найдите поле с изображением (Header image, Gallery и т.д.)
2. Нажмите **Choose an image**
3. Откроется окно медиабиблиотеки с двумя вкладками:
   - **Search** — поиск среди уже загруженных фото
   - **Upload** — загрузка нового фото
4. Перейдите на вкладку **Upload**
5. Нажмите **Or choose from your computer** (или перетащите файл мышкой в эту область)
6. В поле **Title** введите понятное название (напр. «Муравленко — вид с дрона»). Это название нужно, чтобы потом легко найти фото в библиотеке. Посетители сайта его не видят
7. Нажмите синюю кнопку **Upload**

### Использование ранее загруженного фото

Если нужное фото уже было загружено раньше (для другой страницы или галереи):

1. Нажмите **Choose an image**
2. На вкладке **Search** введите название или часть названия
3. Пролистайте результаты и нажмите на нужное фото
4. Оно автоматически вставится в поле

> 💡 Одно и то же фото можно использовать на нескольких страницах. Не нужно загружать его повторно.

### Замена фото на странице

1. Откройте страницу на редактирование (Edit)
2. Рядом с текущим фото будут кнопки **Change image** и **Clear**
3. **Change image** — заменить на другое фото
4. **Clear** — убрать фото совсем
5. После замены нажмите **Publish**

### Медиабиблиотека

Все загруженные изображения хранятся в одном месте:

1. В боковом меню нажмите **Images**
2. Откроется сетка с миниатюрами всех загруженных фото
3. Используйте поиск вверху для нахождения нужного фото
4. Нажмите на фото, чтобы увидеть его детали — размер, где используется, когда загружено

### Рекомендации по изображениям

| Параметр | Рекомендация | Почему |
|----------|-------------|--------|
| **Формат для фотографий** | JPEG (.jpg) | Меньший размер файла |
| **Формат для схем** | PNG (.png) | Чёткие линии и текст |
| **Максимальный размер** | 10 МБ | Ограничение системы |
| **Ширина для шапки** | от 1600 пикселей | Занимает всю ширину экрана |
| **Ширина для галереи** | от 1200 пикселей | Открывается на весь экран |
| **Оптимальный диапазон** | 1200–2500 пикселей | Баланс качества и скорости |

> ⚠️ Фото менее 800 пикселей в ширину будут выглядеть размытыми. Фото более 5000 пикселей будут долго загружаться. Если у вас фото с камеры (4000+ пикселей) — можно уменьшить перед загрузкой в любом графическом редакторе.

## 12. Текстовый редактор (Rich Text)

В полях **Body**, **Description** и **Abstract** доступен визуальный редактор. Он похож на упрощённый Word — с панелью инструментов вверху.

### Панель инструментов

| Кнопка | Что делает | Когда использовать |
|--------|-----------|-------------------|
| **B** | **Полужирный** текст | Для выделения важных слов и терминов |
| **I** | *Курсив* | Для названий, латинских терминов |
| **H2** | Заголовок 2 уровня | Для основных разделов текста |
| **H3** | Заголовок 3 уровня | Для подразделов |
| **🔗** | Вставка ссылки | Для ссылок на внешние ресурсы |
| **UL** | Маркированный список | Для перечислений (• пункт) |
| **OL** | Нумерованный список | Для пронумерованных шагов (1, 2, 3...) |
| **Image** | Вставка картинки в текст | Для иллюстраций прямо в тексте |

### Как сделать текст жирным

1. Выделите нужный текст мышкой (зажмите левую кнопку и проведите)
2. Нажмите кнопку **B** на панели
3. Текст станет **полужирным**
4. Чтобы убрать жирность — выделите текст снова и нажмите **B** ещё раз

### Как вставить ссылку

1. Выделите текст, который должен стать кликабельной ссылкой (например, слова «читать статью»)
2. Нажмите кнопку **🔗** (цепочка) на панели
3. В появившемся окне введите полный URL-адрес (например, `https://doi.org/10.xxxx`)
4. Нажмите **OK** или **Insert**
5. Текст станет подчёркнутым — это теперь ссылка

### Как вставить список

1. Поставьте курсор в нужное место текста
2. Нажмите **UL** (маркированный) или **OL** (нумерованный) на панели
3. Введите первый пункт, нажмите **Enter**
4. Введите второй пункт, нажмите **Enter**
5. Чтобы закончить список — нажмите **Enter** дважды

### Как вставить изображение прямо в текст

1. Поставьте курсор в то место текста, где должна быть картинка
2. Нажмите кнопку **Image** на панели инструментов
3. Выберите уже загруженное фото или загрузите новое
4. Картинка появится внутри текста

> 💡 Не пытайтесь создавать сложное оформление (колонки, цветной фон, таблицы) — редактор предназначен для простого текста с базовым форматированием. Этого более чем достаточно для научного контента.

## 13. Черновики и публикация

Внизу каждой страницы редактирования есть кнопки сохранения. Важно понимать разницу между ними:

### Три режима сохранения

| Действие | Что происходит | Когда использовать |
|----------|---------------|-------------------|
| **Save Draft** | Изменения сохранены в CMS, но на сайте **ничего не меняется** | Работа не закончена, хотите продолжить позже |
| **Publish** | Изменения **сразу видны** всем посетителям сайта | Всё готово и проверено |
| **Unpublish** | Страница **исчезает** с сайта, но остаётся в CMS | Нужно временно скрыть страницу |

> Кнопка **Unpublish** находится в выпадающем меню «…» (три точки) рядом с кнопкой Publish.

### Рекомендуемый порядок работы

1. Внесите все изменения
2. Нажмите **Save Draft** — это сохранит вашу работу
3. Нажмите **Preview** (если доступна) — посмотрите, как будет выглядеть
4. Если всё хорошо — нажмите **Publish**
5. Откройте публичный сайт в браузере и проверьте результат

### Как найти свои черновики

1. В боковом меню нажмите **Pages**
2. Страницы-черновики будут отмечены словом **Draft** рядом с названием
3. Нажмите на карандаш (📝), чтобы продолжить работу

## 14. Удаление контента

### Удаление страницы (город, экспедиция, новость)

1. Перейдите в раздел (например, Pages → Root → нажмите на текст «Города»)
2. Найдите нужную страницу в списке
3. Нажмите **⋮** (три точки) справа от названия
4. Выберите **Delete**
5. Wagtail покажет предупреждение и список связанного контента
6. Подтвердите удаление

### Удаление блока (публикация, участник, фото в галерее)

1. Откройте родительскую страницу на редактирование (📝)
2. Найдите нужный блок, прокрутив вниз
3. Нажмите **Delete** (🗑 корзина) справа от блока
4. Блок визуально станет перечёркнутым
5. Нажмите **Publish** для окончательного удаления

> ⚠️ **Внимание!** Удалённые страницы **нельзя восстановить**. Перед удалением убедитесь, что информация вам точно не нужна.

> 💡 **Спасательный трюк:** если вы нажали Delete на блоке, но ещё **не нажали Publish** — просто обновите страницу в браузере (клавиша F5 или Ctrl+R). Все несохранённые изменения откатятся, и блок вернётся.

## 15. Типичные ошибки и как их избежать

### ❌ «Я добавил контент, но на сайте его нет»

**Причина:** Вы нажали Save Draft вместо Publish.

**Решение:** Откройте страницу на редактирование и нажмите зелёную кнопку **Publish**.

---

### ❌ «Нажимаю на раздел, но открывается редактирование, а не список страниц внутри»

**Причина:** Вы нажали на карандаш (📝) вместо названия раздела.

**Решение:** Нажмите именно на **текст** названия раздела (например, «Города»). Тогда откроется список дочерних страниц с кнопкой Add child page.

---

### ❌ «Хочу добавить публикацию, но не могу найти кнопку Add child page»

**Причина:** Публикации — это блоки на странице, а не отдельные страницы.

**Решение:** Нажмите карандаш (📝) рядом со строкой «Публикации» → прокрутите вниз до раздела Publications → нажмите **Add** там.

---

### ❌ «Фото на сайте размытое или пиксельное»

**Причина:** Загружено слишком маленькое изображение.

**Решение:** Загрузите фото шириной не менее 1200 пикселей. Для шапки — не менее 1600 пикселей.

---

### ❌ «Вижу изменения в CMS, но на сайте всё по-старому»

**Причина:** Браузер показывает закэшированную (сохранённую) версию страницы.

**Решение:** Нажмите **Ctrl+Shift+R** (или Cmd+Shift+R на Mac) — это принудительное обновление страницы.

---

### ❌ «Случайно удалил блок»

**Решение:** Если ещё **не нажали Publish** — нажмите F5 (обновить страницу). Все несохранённые изменения исчезнут, и удалённый блок вернётся.

Если уже нажали Publish — блок удалён. Придётся добавить его заново.

---

### ❌ «Ссылка DOI на сайте не кликается»

**Причина:** В поле DOI введён только номер (10.xxxx/xxxxx) без полного URL.

**Решение:** Введите полный адрес, начиная с `https://`:
`https://doi.org/10.1234/example`

---

### ❌ «Не могу загрузить фото — ничего не происходит»

**Возможные причины:**
- Файл слишком большой (более 10 МБ) — уменьшите размер
- Неподдерживаемый формат — используйте JPEG или PNG
- Проблемы с интернет-соединением — попробуйте ещё раз

## 16. Что делать если что-то сломалось

### Сайт не открывается (ошибка 502, 504 или белый экран)

Серверный процесс мог остановиться. Если у вас есть доступ к серверу по SSH:

```
systemctl restart oilgascity-wagtail
```

Подождите 10 секунд и обновите страницу. Если не помогло — обратитесь к разработчику.

---

### Панель управления (CMS) не открывается

1. Проверьте адрес: `https://oilgascity.ru/cms/` (с `/cms/` на конце, не забудьте косую черту)
2. Попробуйте другой браузер
3. Если не помогло — перезапустите сервис (команда выше)

---

### Забыли пароль от CMS

Подключитесь к серверу по SSH и выполните:

```
cd /opt/oilgascity-wagtail/backend
source ../venv/bin/activate
set -a; . /etc/oilgascity-wagtail.env; set +a
python manage.py changepassword <ваш логин>
```

Система попросит ввести новый пароль дважды. После этого войдите в CMS с новым паролем.

---

### Хочу отменить изменения и вернуть старую версию страницы

Wagtail сохраняет историю всех изменений:

1. Откройте страницу на редактирование (📝)
2. Вверху страницы найдите вкладку **History** (История)
3. Вы увидите список всех сохранённых версий с датами
4. Нажмите **Review this revision** рядом с нужной версией
5. Убедитесь, что это нужная версия
6. Нажмите **Publish** — страница вернётся к этой версии

---

### При любых серьёзных проблемах

Свяжитесь с разработчиком. Для диагностики потребуется SSH-доступ к серверу сайта.

## 18. Глоссарий терминов

| Термин | Что это значит простыми словами |
|--------|-------------------------------|
| **CMS** | Система управления сайтом — интерфейс для редактирования контента без программирования |
| **Pages (Страницы)** | Главный раздел CMS, где хранится весь контент сайта |
| **Root (Корень)** | Верхний уровень — «папка», в которой лежат все разделы сайта |
| **Child page** | Дочерняя страница — страница внутри раздела (город внутри «Городов») |
| **Edit** | Редактировать — открыть страницу для изменений |
| **Publish** | Опубликовать — сделать изменения видимыми на сайте |
| **Draft** | Черновик — сохранённая, но не опубликованная версия |
| **Unpublish** | Снять с публикации — скрыть страницу с сайта, не удаляя её |
| **Inline-блок** | Запись, добавляемая прямо на странице кнопкой Add (публикация, участник) |
| **Gallery** | Галерея — набор фотографий с подписями |
| **Lightbox** | Режим просмотра фото на весь экран (открывается по клику на фото) |
| **Header image** | Главное изображение страницы, отображаемое вверху |
| **Caption** | Подпись к фотографии в галерее |
| **Rich Text** | Текстовое поле с возможностями форматирования (жирный, курсив, ссылки) |
| **Media** | Все загруженные на сайт файлы — фото, документы |
| **Revision** | Сохранённая версия страницы в истории (можно откатиться назад) |
| **Preview** | Предпросмотр — посмотреть, как страница будет выглядеть до публикации |
| **DOI** | Уникальный идентификатор научной статьи (ссылка вида doi.org/...) |
| **ORCID** | Уникальный идентификатор учёного (ссылка вида orcid.org/...) |
| **SSH** | Способ удалённого подключения к серверу через командную строку |
