# geoportal Specification

## Purpose
Определяет поведение геопортала проекта: состав слоёв, переключение городов и подложек,
легенды и подписи объектов.

## Requirements

### Requirement: Слои по картам статей
Геопортал SHALL показывать для каждого города группы слоёв, повторяющие карты статей проекта,
с легендой у каждого включённого слоя и указанием источника.

#### Scenario: Включение слоя
- **WHEN** посетитель включает слой «Классификация типов поверхности»
- **THEN** слой появляется на карте, под названием слоя видна легенда классов

### Requirement: Переключение города
Геопортал SHALL переключать город кнопкой и по параметру адреса `?city=<slug>`, показывая
слои только выбранного города и перемещая карту к его границам.

#### Scenario: Переход со страницы города
- **WHEN** посетитель открывает `/geoportal?city=kogalym`
- **THEN** карта показывает Когалым и его слои

### Requirement: Подпись объекта
По щелчку на объект слоя с подписью геопортал SHALL показывать всплывающее окно с названием
объекта на русском языке и его характеристиками.

#### Scenario: Щелчок по классу поверхности
- **WHEN** посетитель щёлкает по участку классификации
- **THEN** появляется подпись с русским названием класса

### Requirement: Вкладка «Жилой фонд»
Геопортал SHALL показывать для каждого города вкладку «Жилой фонд» с домами, окрашенными по
десятилетию постройки, цифрами реестра и графиком «Когда строился город»; щелчок по десятилетию
на графике или в легенде MUST оставлять на карте только дома этого десятилетия.

#### Scenario: Фильтр по десятилетию
- **WHEN** посетитель открывает `/geoportal?city=kogalym&tab=housing` и щёлкает столбец «1980-е»
- **THEN** на карте остаются дома 1980-х, видна плашка «Показаны дома: 1980-е» с кнопкой «Показать все»
