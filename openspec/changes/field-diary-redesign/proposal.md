## Why

Сайт нужен прежде всего для отчёта по гранту РНФ 25-27-00022: эксперты должны наглядно
увидеть результаты и всю накопленную фактуру (снимки, карты, публикации, доклады, архивы).
Текущий фронтенд (Inter, «стеклянные» карточки, анимации) этого не показывает: разделы
скудные, текст прячется за анимацией появления, нет мобильного меню, адреса городов
числовые. Владелец выбрал макет «Полевой дневник» v2 (`design-concepts/concept-3-v2/`)
и попросил сразу заменить им основной сайт, чтобы передать коллегам на рассмотрение.

## What Changes

- Новый фронтенд по макету v2: шапка с разделами «О проекте, Муравленко, Когалым,
  Результаты, Материалы, Новости» и кнопкой «Геопортал», страницы городов по адресам
  `/cities/muravlenko` и `/cities/kogalym`, страницы «Результаты» и «Материалы».
- Справочный слой: нумерованные рисунки с источниками, метаданные снимков, оглавления,
  паспорт города, библиографические записи, блок «Как цитировать», формула благодарности РНФ.
- В CMS: новая модель страницы `ReportPage` с блочным содержимым (StreamField) для
  результатов по годам и материалов; новые поля главной (цифры проекта, ключевые слова,
  аннотация на английском), города (паспорт, блоки содержимого), публикаций (статус,
  библиографическая запись), снимков галерей (тема, дата, автор).
- Контент новых разделов заводится загрузчиком вне репозитория (`content-drafts/`), репозиторий
  публичный и тексты отчёта в него не попадают; дальше правится в админке.
- **BREAKING** для старых адресов: `/blog`, `/publications`, `/team`, `/expeditions`, `/cities/<id>`
  перенаправляются на новые.
- Удаляются зависимости фронтенда tailwindcss, framer-motion, leaflet, lucide-react;
  добавляется maplibre-gl (общий движок с геопорталом).
