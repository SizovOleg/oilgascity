## Decisions

1. **Результаты 2026 без нового кода.** Используются те же блоки ReportPage, статусы результата
   (`done`, `partial`, `progress`) уже есть в модели. «Заявлено» взято из плана 2026 года заявки,
   «сделано» из статьи о Когалыме после рецензии, слоёв и описания экспедиции. Пункты без данных
   честно помечены «в работе».
2. **Климат Когалыма** считается по ближайшей станции с длинным рядом (Сургут, около 120 км,
   GHCN-Daily из архива D:/test/aisori), сравниваются тридцатилетия 1961-1990 и 1996-2025, годы
   с заполнением меньше 90% отбрасываются. Подписан как предварительный расчёт для сайта.
   Снег не показан: ряд высоты снежного покрова неполный.
3. **Жилой фонд из housing-yanao.** Год и жилая площадь только из ГИС ЖКХ. В Когалыме 57 пар
   из review-proposals.json (совпали адрес, общая площадь и этажность, подтверждены независимой
   проверкой) показаны как отдельный источник «кандидат», 299 контуров OSM как вспомогательные.
   Это не меняет исходный проект housing-yanao.
4. **Вкладки в манифесте** (`cities[].tabs`); старый формат с `groups` читается как одна вкладка.
   Фильтр по полю слоя задаётся в манифесте (`filter: "decade"`).
5. **Движение не прячет текст:** начальная прозрачность 0,35, а не 0; эффекты только при
   `prefers-reduced-motion: no-preference`.

## Risks / Trade-offs

- [Статья о Когалыме ещё на рецензировании] → решение владельца; в тексте указан статус рукописи.
- [В статье противоречие: в обсуждении «необеспечена правобережная часть», в аннотации и
  заключении хуже обеспечена левобережная] → на сайте вариант аннотации и заключения, владелец
  предупреждён.
- [Загрузчики перезаписывают разделы] → порядок запуска: load_v2.py, load_2026.py, load_housing.py.
