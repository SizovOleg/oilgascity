## Why

Загрузки сайта (фото, их уменьшенные копии, документы) лежат на диске общего сервера
antigravity-2, где живут и другие сайты. Владелец решил держать весь медиаконтент во
внешнем объектном хранилище: так диск сервера не растёт с каждым фото, а тот же шаблон
затем переносится на сайт по геоморфологии (reliefwestsib.ru), где фотографий много.
Сделать сейчас удобно: медиа пока мало (66 файлов, 97 МБ), перенос быстрый.

## What Changes

- Wagtail сохраняет новые загрузки (оригиналы изображений, рендеры, документы) в
  отдельный публичный бакет Backblaze B2 через S3 API (пакет `django-storages`).
- Включение по флагу `MEDIA_STORAGE=s3` в файле окружения сервера; без флага всё
  остаётся на локальном диске, как сейчас (локальная разработка, тесты, откат).
- Адреса медиа не меняются: файлы по-прежнему открываются по
  `https://oilgascity.ru/oilgascity-media/...`; nginx берёт их из бакета и кэширует
  у себя (`proxy_cache`).
- Документы Wagtail отдаются через Django (`/documents/...`), а не прямой ссылкой
  в бакет, чтобы работали ограничения доступа к коллекциям.
- Существующие 66 файлов копируются в бакет скриптом переноса с проверкой числа
  файлов; локальная папка `media/` остаётся резервом до решения владельца.
- После переключения ежемесячный бэкап (`scripts/backup.sh`) сокращается до базы:
  медиа уже лежат во внешнем хранилище.
- Не входит: сайт reliefwestsib (другой репозиторий, повторит шаблон позже), геоданные
  и PostGIS (остаются на сервере), CDN стороннего провайдера.

## Impact

- Код: `backend/backend/settings/production.py` (настройки хранилища по флагу),
  `backend/requirements.txt` (`django-storages[s3]`, `boto3` с фиксированными версиями),
  тесты в `backend/home/tests.py`.
- Сервер: новые переменные в `/etc/oilgascity-wagtail.env` (бакет, endpoint, ключ),
  новый `location /oilgascity-media/` и зона `proxy_cache` в nginx (nginx общий для
  нескольких сайтов: `nginx -t` и бэкап конфига обязательны).
- Внешняя система: публичный бакет B2 и ключ приложения только к нему; создаёт
  владелец в консоли Backblaze, ключи вписывает в файл окружения сам.
- Скрипты: `scripts/migrate-media-to-b2.sh` (перенос), правка `scripts/backup.sh`.
- Риск: известная несовместимость B2 с заголовками checksum в boto3 ≥ 1.35.99
  (django-storages #1498), учтена в дизайне.
