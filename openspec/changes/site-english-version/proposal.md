## Why

Владелец хочет, чтобы иностранный читатель понял, о чём проект, увидел его фактуру (цифры, графики, карты,
выводы) и мог написать авторам (обсуждение 23.11.2026). Сейчас сайт только на русском, а контактов авторов нет
ни у кого: в карточке участника нет поля e-mail, профили заполнены только у руководителя.

Решения владельца:
- переводятся все страницы: «О проекте», города, результаты 2025 и 2026, публикации, команда, материалы,
  экспедиции и блог;
- перевод полный, 1:1; цифры, графики и рисунки общие с русской версией;
- геопортал: интерфейс, названия слоёв, легенды, подписи, README в скачиваемых файлах;
- контакты: адрес руководителя в подвале и на главной, личные адреса в карточках только с согласия
  (адреса владелец пришлёт позже, поле пока пустое);
- имена латиницей как в опубликованных статьях, список на проверку владельцу;
- английские страницы публикуются сразу, владелец вычитывает на сайте; каждую партию перевода проверяет
  отдельно модель Fable;
- выводы по Когалыму переводятся так же, как опубликованы по-русски.

## What Changes

- Wagtail: языки контента ru и en, дополнение wagtail-localize (синхронный перевод: тексты блоков
  переводятся, числа, рисунки и структура общие, при правке русского видно устаревшие фразы).
- Существующий язык страниц переименовывается из en (значение по умолчанию) в ru.
- Поле e-mail у участника команды, общий контакт проекта.
- Фронтенд: адреса /en/..., переключатель RU/EN, словарь интерфейса, запросы к API с языком.
- Геопортал: английские подписи в манифесте и словарь интерфейса, README скачиваемых слоёв на двух языках.
- Перевод страниц партиями через PO-файлы wagtail-localize, проверка Fable, публикация.

## Capabilities

### New Capabilities
- `site-english`: английская версия сайта и геопортала, контакты авторов.

### Modified Capabilities
- `geoportal`: английский интерфейс и подписи.

## Impact

`backend/` (настройки, модели, миграции, requirements), `frontend/src/` (маршруты, API, словари,
геопортал), `scripts/geodata/build_geodata.py`. База на проде: новые таблицы wagtail-localize, переименование
языка, английские копии страниц. Перед выкаткой снимается копия базы.
