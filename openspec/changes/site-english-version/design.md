## Context

Wagtail 7.3rc1 headless (API v2 на /wt-api/v2/), фронтенд React, база SQLite (3,4 МБ) на сервере. Все 26 страниц
сейчас в языке en (Locale id 1), потому что `LANGUAGE_CODE = "en-us"`, а i18n Wagtail выключен. Деплой
(`scripts/deploy.sh`) сам ставит зависимости и выполняет миграции, копию базы не снимает.

## Decisions

### Инструмент перевода: wagtail-localize 1.14.5
Требует Django ≥ 5.2 и Wagtail ≥ 7.0, ставит только себя и polib. Переводит страницу как набор текстовых
сегментов (в том числе внутри StreamField и дочерних записей), нетекстовые поля (числа, рисунки, ссылки)
синхронизирует с оригиналом; после правки русской страницы в переводе видны новые и изменённые сегменты.
Перевод можно выгрузить и загрузить PO-файлом, это и есть способ работы: сегменты выгружаются скриптом,
переводятся, проверяются, загружаются и публикуются.
Альтернатива: встроенный `wagtail.contrib.simple_translation` (копия страницы без синхронизации). Отклонено:
при полном переводе 1:1 правки русской версии пришлось бы переносить вручную без подсказки, что устарело.
Риск: официально протестированные версии Django у дополнения могут отставать от 6.0, поэтому всё проверяется
на копии боевой базы до выкатки.

### Языки
`LANGUAGE_CODE = "ru"`, `WAGTAIL_I18N_ENABLED = True`, `WAGTAIL_CONTENT_LANGUAGES = LANGUAGES = [ru, en]`.
Миграция данных переименовывает Locale «en» в «ru», если «ru» ещё нет (страницы остаются на месте),
затем создаётся «en» для переводов. `wagtail.locales` заменяется на `wagtail_localize.locales`.

### Фронтенд
Маршруты с необязательным префиксом /en (тот же набор страниц). Контекст языка: запросы к API получают
`&locale=en`, словарь строк интерфейса (меню, кнопки, подписи), атрибут `lang` документа, hreflang.
Переключатель RU/EN в шапке ведёт на ту же страницу в другом языке.

### Геопортал
Манифест получает английские варианты подписей (`title_en`, `note_en`, подписи легенд и полей), фронтенд
выбирает по языку. Значения в таблицах (адреса, названия скверов) остаются как есть.
README скачиваемых файлов двуязычный.

### Контакты
`TeamMember.email` (необязательное). На странице адрес собирается скриптом при показе, чтобы не отдавать его
сборщикам спама в HTML. Общий контакт проекта в настройках сайта (поле на главной странице).

### Перевод и проверка
Перевожу сам по сегментам, термины держу единым словарём (green infrastructure, urban open spaces, housing
stock, field description points...). Каждую партию проверяет субагент на модели Fable: точность против русского,
цифры, термины, имена. Замечания вношу до публикации партии.

## Risks / Trade-offs

- [Совместимость wagtail-localize с Django 6] проверка на копии базы локально до выкатки.
- [Изменение боевой базы] копия базы перед выкаткой (`sqlite3 .backup`), откат: вернуть файл и предыдущий коммит.
- [Размер работы] партии: интерфейс и «О проекте» с командой, затем города и результаты, затем остальное.
